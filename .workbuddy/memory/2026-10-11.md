### 踩坑记录

1. **sshpass 装不上**：brew tap 时 GitHub 又连不上（代理故障），
   且清理 tap 目录被安全策略拦。→改用 **Python pexpect** 驱动 ssh/scp，
   在 `~/.workbuddy/binaries/python/envs/default/` venv 里装（不污染系统）

2. **sudo 密码交互卡死**：`sudo -v` + 自定义提示串时 pexpect 没匹配上，
   进程挂住 7 分钟。→ 改用 `echo '<pw>' | sudo -S -p 'SUDOPW:' bash -c '<cmd>'`，
   同时 ssh 加 `-n` 避免 stdin 冲突

3. **scp 上传目录会嵌套**：`scp -r dist /path/dist` 会得到 `/path/dist/dist`。
   但这次**实际没发生**——我误判了。看到 `find` 显示 `dist/assets` 才对，
   说明结构本来就是对的。以后先`find -maxdepth 3 -type d` 看清再动手，
   别急着 mv（那次失败的 mv 如果真执行了反而会破坏正确结构）

4. **凭据文件不入库**：临时 python 脚本用完即删，.gitignore 加
   `scripts/_ssh_*.py`、`scripts/_scp_*.py` 防将来误提交
