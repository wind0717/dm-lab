# 2026-10-06

## dm-lab 项目评审与部署方案

产出 `项目评审与部署方案.md`（项目根目录）。仅静态分析，未改源码。

### 项目现状
- 纯静态 SPA：零后端、零 fetch、零 CDN 依赖，`base: './'` 相对路径 → 静态托管零门槛
- 算法层（`src/lib/*.ts`）与 UI 严格分离，零 React 依赖，可独立测试
- 16,209 行 src / 6 大模块 / 14 个子页面 / 12 个逐步推演页
- 自建 `scripts/audit.mjs`（Puppeteer 全页遍历 + 横向溢出检测，41 张截图）

### 定位的 P0 问题
1. **无 URL 路由** —— `App.tsx:25` 用 `useState<PageId>`，无法把具体实验分享给学生。`react-router@7.6.1` 已装但零引用
2. **零状态持久化** —— localStorage/sessionStorage/indexedDB 全项目 0 处，刷新丢全部参数与 CSV
3. **`datasets.ts` 漏了种子随机** —— classifiers/metrics/clusterMetrics/preprocess 都用了 `mulberry32`，唯独 datasets.ts 全是 `Math.random()`，实验不可复现

### 其他关键发现
- 包体 810KB 单块（gzip 239KB），无 React.lazy、无 manualChunks → 首屏下全站
- 无 Web Worker，XGBoost 50 轮/RF 50 树在 5000 行 CSV 下会阻塞 UI
- 11 张 `<table>` 无 `overflow-x-auto`；13 处裸 `grid-cols-*`（响应式断点实际有 30 余处）
- 26 条 ESLint error（14 条 set-state-in-effect + 10 条 only-export-components）
- **git 零提交、无 remote** → 源码无版本保护，最大风险
- 19 个手写 smoke/selftest 脚本，但 package.json 无 `test` script、无测试框架、无 CI
- `lan-server.cjs` 无鉴权/无 HTTPS/无安全头，**不可暴露公网**
- 无 XSS 面：dangerouslySetInnerHTML/innerHTML/eval 全 0 处；CSV 仅在浏览器内存解析，不上传

### 部署结论
`npm run build`（实测 10.4s 成功）→ `dist/`（3 文件 892KB）传任意静态托管。
国内高校学生建议腾讯云/阿里云 COS+CDN 或校内 Nginx；快速验证用 Cloudflare Pages。

### 建议实施顺序
阶段1 立即上线 + git 提交 → 阶段2 路由+存档+lazy（半天）→ 阶段3 移动端（半天）→ 阶段4 接 cloud-service 做学号+作业闭环（唯一需后端的阶段）。
