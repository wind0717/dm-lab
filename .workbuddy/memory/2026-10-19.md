### 模块二标题修正（用户指出）

原标题「数据预处理：垃圾进，垃圾出」**逻辑自相矛盾**：
既然输出还是垃圾，预处理的意义是什么？

原意是借用 GIGO 谚语，但放在预处理模块上完全说反了——
预处理正是为了**避免** GIGO。

改为：
- 页面主标题 → 「把脏数据洗干净再送进模型」
- 首页卡片 → 「脏数据进，干净数据出」
- 文件头注释同步

**教训**：引用谚语要看语境。GIGO 描述的是"不处理的后果"，
而预处理模块要表达的是"处理的价值"。

### 踩坑

**SSH 连接限流**：连续多次 ssh/scp 会被服务器断开
（`Connection closed by 168.107.40.86 port 22`）。
解决：改用 rsync 代替 scp（带断点续传），并在命令间 sleep 8秒。
另外 `SSHOPT="-i $KEY ..."` 这种写法在 zsh 里不会拆词，
必须写成 `ssh -i "$KEY" ...` 直接展开。

### 运维命令

```bash
KEY=/Users/vambear/Documents/securityfile/kra.key
ssh -i $KEY ubuntu@168.107.40.86

sudo systemctl status dm-lab      # 状态
sudo systemctl restart dm-lab     # 重启
sudo journalctl -u dm-lab -f      # 实时日志
curl localhost:8090/healthz       # 健康检查

# 回滚
sudo ln -sfn /opt/dm-lab/releases/<旧版本> /opt/dm-lab/current
sudo systemctl restart dm-lab
```
